# Mohan Akash — React Portfolio v2

Modern React/Vite portfolio with:
- Dark/light mode
- Framer Motion entrance and hover animations
- Animated AI hero/orbit
- Responsive mobile navigation
- Scroll progress indicator
- Current AI engineering work: RAG, OCR/document processing, Azure AI Foundry, LLMs, Langfuse, FastAPI/ETL
- All major projects from the old portfolio
- Education, certifications, GitHub, LinkedIn and contact links

## Run locally
npm install
npm run dev

## Build
npm run build

## GitHub Pages
This project is configured for the repository path `/my_portfolio/`.
Push the project files to the repository and enable GitHub Pages using the built `dist` output or a Pages-compatible deployment workflow.

## Important
Keep descriptions of company work high-level and public-safe. Do not publish confidential Kshema architecture, data, client information, credentials or proprietary implementation details.
